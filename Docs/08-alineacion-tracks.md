# 🏆 Alineación Estratégica con los Tracks del Hackathon

*Documento que justifica la elección de los tracks y desafíos del hackathon para asegurar la máxima viabilidad y puntuación del proyecto LicitaBot (SICOES-Agent).*

---

## 1. 📊 Bolivia Data Track (Calidad del dato, no cantidad)

**¿De qué trata?**
Se centra en resolver la carencia de datos limpios, estructurados, curados y accesibles en el contexto boliviano y latinoamericano. No busca acumular millones de filas crudas, sino procesar datos locales con un gran rigor metodológico.

**Formas válidas de proyectos:**
- Un dataset curado, publicado y documentado (en HuggingFace o GitHub) con metadatos y pipelines reproducibles.
- Arquitecturas de procesamiento (ETL/ELT).
- Un producto construido sobre esos datos (una app, dashboard interactivo o API pública).
- Datos sintéticos documentados (si no existen datos reales).
- Sistemas RAG para consultar datos estructurados en lenguaje natural.

**Entregables mínimos requeridos:** Dataset público, pipeline reproducible, documentación completa de fuentes y limitaciones, visualización interactiva y deploy en producción.

---

## 2. 🤖 Bolivia Agents Track (Productos con agentes que funcionan de verdad)

**¿De qué trata?**
Su objetivo es construir software autónomo impulsado por Inteligencia Artificial donde un "agente" perciba un contexto, tome decisiones, utilice herramientas y entregue un resultado real (no un simple chatbot con un *prompt* largo).

**Formas válidas de proyectos:**
- Agentes de automatización autónomos (para research avanzado, reportes, análisis).
- Productos conversacionales o con voz con casos de uso reales.
- Agentes conectados a datos que generen alertas o acciones.
- Herramientas de productividad vertical o SaaS con agentes embebidos.

**Entregables mínimos requeridos:** Producto deployado y accesible vía web o API, demo en vivo funcional durante el *pitch* (no videos grabados), repositorio con README claro, y un caso de uso enfocado en resolver un problema real de Bolivia/LatAm.

---

## 3. 🎯 Nuestra Estrategia Ganadora: ¿Por qué elegimos este enfoque?

Teniendo en cuenta los intereses del equipo y el contexto de innovación local (financiera, educación, civic tech o sostenibilidad), el **"Bolivia Agents Track" combinado con el desafío de Zavu** ofrece el mayor impacto para destacar ante el jurado. 

Esta combinación permite construir un producto funcional y visualmente muy atractivo rápidamente, apalancándose fuertemente en el uso de herramientas de IA.

### La Propuesta de Proyecto Ideal (Alto valor diferencial)
- **El Producto Core (Agents Track):** Un Agente Autónomo de Monitoreo de Licitaciones (SICOES) diseñado para actuar como analista de mercado/ventas del Estado para las PyMEs.
- **El Toque Extra (Desafío Zavu):** Integración directa de la API de **Zavu** para que el agente, tras razonar y tomar una decisión, envíe proactivamente alertas inteligentes y notificaciones multicanal (Telegram, SMS) directo al teléfono del usuario. Esto demuestra que la IA puede integrarse perfectamente en el flujo diario de los usuarios sin que ellos deban aprender a usar interfaces nuevas complejas.
